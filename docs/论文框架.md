# 论文框架与方法定位

> 本文档给出论文的定位、贡献点、章节结构与叙事建议，确保实验结论与论文主张一致。

## 一、定位（重要）

**主方法 = 源论文 dual-stage RL 的 E-bus 适配版**（单多头 PPO 决策时机/数量 + 启发式选车）。
**双 PPO 联合智能体 = 对比/ablation 方案**（实验显示其在同质车队上劣于主方法）。

> ⚠️ 不再把"双 PPO 联合"作为论文提出的主方法——实验不支持。改为"对比方案"，这恰是严谨的科研态度（让实验指导结论）。

## 二、标题建议

- *Dual-Stage Reinforcement Learning with Heuristic Coordination for Electric Bus Scheduling and Charging Management*
- 或：*电动公交车调度与充电协同管理的双阶段强化学习方法*

## 三、贡献点（4 条，可直接写进论文）

1. **E-bus 调度+充电的联合 RL 建模**：区别于 E-taxi，针对公交**固定线路、同质车队、聚合客流、连续多日运营**的特点建立 MDP（含高峰拥堵、分时电价、乘客流失、多日电池继承）。
2. **dual-stage RL 的 E-bus 适配**：将源论文方法迁移并适配——充电决策简化为数量决策、电量排序启发式选车、经济标定的 reward。
3. **双 PPO 联合 vs dual-stage 的系统对比**：在多种设置（多天、拥堵、集中式 critic）下证明**同质车队下启发式协调更优**，揭示动作解耦的适用边界。
4. **现实因素的综合考量与策略可解释性**：分时电价敏感性（低谷充电 91%）、客流峰谷响应、多日电池管理；并给出可解释的全天调度策略。

## 四、章节结构

### 1. 引言
- 智能交通与电动公交背景；电动公交调度+充电的挑战（异构决策、动态性、资源约束）。
- 引出 dual-stage RL 思路（承接本组 E-taxi 前作），说明 E-bus 场景的新特点。
- 贡献点（上述 4 条）。

### 2. 相关工作
- 公交调度优化方法（传统优化、启发式、RL）。
- 电动车辆充电管理（分时电价、充电规划）。
- RL 在交通调度中的应用（含源论文 E-taxi dual-stage）。

### 3. 系统模型与问题建模
- E-bus 系统：线路、车队（同质）、充电桩、客流、分时电价。
- MDP：状态（每车位置/电量/状态、桩空闲数、客流、电价）、动作（发车数量、充电数量）、转移（含拥堵、多日）、约束。
- 优化目标：最大化 **总收益 = 接客收入 − 等待成本 − 流失损失 − 充电花费 + 末剩余电量价值**。

### 4. 方法
- 4.1 总体框架：dual-stage（RL 决策时机/数量 + 启发式选车）。
- 4.2 RL 部分：单多头 PPO（发车头 + 充电头），动作掩码（动态决策时机）。
- 4.3 启发式协调：电量最高发车、电量最低充电。
- 4.4 reward 设计：经济标定（票收/等待/电费/流失）。
- 4.5 对比方案：双 PPO 联合智能体（集中式 critic）——用于 ablation。

### 5. 实验与结果
- 5.1 实验设置（实例、参数、基准）。
- 5.2 主对比：dual-stage vs 双PPO联合（收敛曲线、SP/CE/总收益/末电量）。
- 5.3 充电策略分析（分时电价敏感性，低谷充电 91%）。
- 5.4 全天策略可视化（车辆甘特、电量轨迹、发车充电时机）。
- 5.5 ablation 与讨论（terminal 奖励影响、解耦的适用边界）。

### 6. 结论
- 总结：dual-stage RL 适配 E-bus 的有效性；同质车队下启发式协调的优势；双PPO联合的局限与适用场景。
